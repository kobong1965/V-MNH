# V-MNH 画布 1.0.0

这是 Windows x64 独立便携版。解压整个压缩包，打开目录里的 `V-MNH Canvas.exe`。请保留同目录的 `resources`、`locales` 和运行库文件。

此包基于当前桌面画布整理，包含项目首页和画布、私密画布、画布素材交给本地 Qwen 的方案确认流程、双显卡调度界面以及图像和视频生成设置。生成前仍需确认。

首次打开从空项目库开始。旧版安装、项目、私密画布及设置保留原样。压缩包不包含账号、API 密钥、已配置的 API 服务、私密画布密码、项目、商品图片、视频、脚本内容或模型权重。应用自带的图标和内部服务属于运行文件。

图像、视频和 Qwen 生成需要在目标电脑上单独配置对应的服务与模型。此便携版不沿用旧版更新通道，也不覆盖旧版安装。
