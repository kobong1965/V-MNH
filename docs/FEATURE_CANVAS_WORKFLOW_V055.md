# V-MNH 0.5.5 画布效率增强规格

> 状态：已批准（用户于 2026-08-09 通过截图和明确指令确认）
> 范围：素材预览、固定屏幕尺寸输入框、框选批量连线、可复用工作流

## 1. 目标

让团队在无限画布里能看清生成节点引用了哪些素材，在任何缩放比例下都能直接填写生成参数；同时支持框选多个素材后一次连到生成节点，并把常用的节点、连线和生成参数保存为工作流，供新画布一键复用。

## 2. 用户可见行为

### 2.1 素材预览

- 图片素材连接到生成节点后，生成节点输入区顶部始终显示有序缩略图。
- 缩略图按 `parentIds` 顺序编号，图像使用真实素材预览，不使用占位图。
- 预览仅展示已连接且有可用图片地址的节点；断开连线后立即消失。

### 2.2 固定尺寸输入框

- 画布节点继续随画布缩放。
- 被选中的生成节点输入面板保持固定屏幕尺寸，不随缩放比例变小或变大。
- 输入面板仍锚定在所属节点下方，并允许正常输入、切换参数和触发生成。

### 2.3 框选与批量连线

- 鼠标左键拖拽空白画布可框选多个节点。
- 选区边界右侧显示一个批量输出端口。
- 从该端口拖到兼容的目标节点，一次把所有被选中的素材节点追加到目标节点的输入连接中。
- 连接顺序遵循选区节点当前的稳定顺序，已存在连接自动去重；混入不兼容节点时不允许提交，避免部分连接造成歧义。

### 2.4 工作流模板

- 顶部左侧“画布 1”右边新增“工作流”入口。
- 可将当前画布保存为命名工作流模板，并查看、使用、删除模板。
- 在任意新画布点击“使用”，把模板节点和连线追加到当前视口附近，不覆盖当前项目。
- 模板保存节点类型、相对位置、连线和生成参数；不保存 API Key、运行状态、任务 ID、错误、历史生成图片/视频或项目媒体结果。
- 模板保存在 Vela 本地数据目录，应用更新后继续保留。

## 3. 非目标

- 本次不实现云端同步、团队共享或 GitHub 工作流市场。
- 不把 ComfyUI 原始 API JSON 暴露在画布工作流面板。
- 不上传 GitHub Release；安装包更新与仓库发布仍是独立操作。

## 4. 验收标准

1. 两个图片节点连接 GPT 图片节点后，输入区显示编号 1、2 的真实缩略图。
2. 在 100% 和 44% 缩放下，输入面板屏幕宽度误差不超过 4 像素。
3. 框选两个图片节点并拖动组选区端口到目标节点后，目标 `parentIds` 同时包含两个节点且无重复。
4. 保存模板、创建新画布、点击“使用”后，节点、连线和参数恢复，旧结果与运行状态不出现。
5. 重启桌面应用后工作流模板仍可见。
6. 自动化测试、生产构建、同图视觉对照通过，并生成 0.5.5 安装包原位升级。
