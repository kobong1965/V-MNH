# V-MNH 0.5.6 框选与素材盘增量规格

状态：实施中
日期：2026-08-09

## 1. 目标

在不改变现有项目数据结构和用户安装入口的前提下，完成以下画布效率增强：

- 精简首页三个重复或无交互入口。
- 多选素材可整组拖动、打组，并明确显示当前选中的素材节点。
- 从多选框连接点拖到空白处时，打开与画布双击一致的“添加节点”菜单；创建后自动连接全部兼容素材。
- 画布顶部移除“算力”，替换为当前项目“素材盘”。
- 成功生成的图片和视频自动进入素材盘，并可再次插入画布。
- 选中图片/视频素材节点时，在节点上方显示裁剪和下载操作条。

## 2. 范围与边界

- “素材盘”只展示当前项目中已经成功生成且具有 `resultUrl` 的图片和视频；上传的输入素材不重复计入。
- 素材盘内容来源于项目节点数据，随现有项目保存机制持久化，不新增数据库表。
- “裁剪”复用现有图片编辑器并把结果写回当前节点；视频节点只提供下载。
- 仅移除画布里的“算力”入口和浮层，不删除 API 设置页中的云算力配置能力。
- 本次不上传 GitHub，不更换安装目录、桌面快捷方式或用户素材目录。

## 3. 交互规格

### 3.1 首页精简

- 删除品牌栏右侧无交互布局图标。
- 删除侧栏重复“项目”导航。
- 删除主页右上角重复“新建项目”按钮；保留侧栏主按钮和空状态按钮。

### 3.2 多选、打组和批量连线

- 框选两个及以上素材节点后，每个选中素材底部显示深色“已选中”条。
- 按住任一已选中素材拖动时，整个选区一起移动。
- 选区顶部显示“打组”；已打组时显示中文组操作。
- 从选区右侧连接点拖到已有兼容节点：一次写入全部兼容父节点并去重。
- 拖到空白画布放开：在放开位置打开“添加节点”菜单；选择节点后，将全部兼容选中素材写入新节点 `parentIds`。

### 3.3 素材盘

- 顶部按钮显示“素材盘”和素材数量。
- 面板支持全部、图片、视频筛选。
- 点击素材缩略图，在当前视口中央插入对应素材节点。
- 新生成成功的素材无需手动保存即可出现。

### 3.4 节点素材操作

- 单选具有结果素材的节点时，节点上方显示固定屏幕尺寸操作条。
- 图片：裁剪、下载。
- 视频：下载。
- 下载文件名包含素材类型和节点 ID；远程 URL 失败时回退到浏览器打开。

## 4. 主要文件

- `src/vela/components/VelaHome.tsx`：首页入口精简。
- `src/vela/components/VelaTopBar.tsx`：素材盘入口。
- `src/vela/components/VelaAssetTray.tsx`：素材盘面板。
- `src/components/canvas/CanvasNode.tsx`：素材操作条和选中暗部。
- `src/components/canvas/SelectionBoundingBox.tsx`：中文打组工具。
- `src/hooks/useConnectionDragging.ts`、`src/hooks/useContextMenuHandlers.ts`、`src/hooks/useNodeManagement.ts`：批量拖线到空白并自动连接。
- `src/App.tsx`：状态编排、素材派生与面板接入。
- `src/vela/libtv.css`：视觉样式。

## 5. 代码约定

```ts
const generatedAssets = nodes.filter((node) =>
  node.status === NodeStatus.SUCCESS
  && Boolean(node.resultUrl)
  && ['gpt-image', 'h3-video', 'image-result', 'video-result'].includes(node.kind || '')
);
```

- 使用现有 React hooks、Lucide 图标和 Vela CSS 命名。
- 不在组件中新增密钥、云端连接或独立持久化副本。
- 批量连接必须稳定排序并使用 `Set` 去重。
