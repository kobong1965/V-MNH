# V-MNH 设置、API 与 GitHub 更新功能规格

## 目标

在项目主页左下角增加“API”和“设置”入口，让团队成员无需进入画布即可完成模型连接、外观切换与版本更新。

## 已确认默认值

- Windows 桌面版和本机 Web 共用同一套设置界面。
- 应用外观支持“跟随系统 / 明亮 / 深色”，画布颜色可独立选择白色或黑色。
- API Key 只提交给本机后端并继续使用现有加密存储；前端、项目文件和日志不保存明文 Key。
- 大模型 API 以 OpenAI 兼容连接为第一类通用连接，支持提示词、图片和视频模型名及可配置端点；云端 ComfyUI 继续作为第二类连接。
- 自动更新使用 GitHub Releases。默认仓库为 `kobong1965/V-MNH`，支持公开仓库；私有仓库可在桌面端填写只读 Token，并通过 Electron `safeStorage` 加密保存在当前 Windows 用户目录。
- Web 版可以查看更新配置，但下载安装仅在 Windows 安装版开放。

## 功能范围

1. 主页导航
   - 左下角固定显示“API”和“设置”。
   - 当前页面有清晰选中态；项目列表保持可用。
2. 外观设置
   - 切换应用模式：跟随系统、明亮、深色。
   - 独立切换白色/黑色画布。
   - 设置写入本机并在重启后恢复。
3. API 管理
   - 查看、新增、编辑、删除、测试 OpenAI 兼容账户。
   - 配置 Base URL、API Key、提示词/图片/视频模型、各接口路径、并发数和超时。
   - 查看并管理现有云端 ComfyUI 连接。
4. GitHub 更新
   - 显示当前版本、更新仓库和更新状态。
   - 检查新版本、下载并安装更新；下载进度同步显示。
   - 无 Release、网络错误、鉴权错误和已是最新版均给出明确提示。

## 技术与命令

- 前端：React 19 + TypeScript + 现有 Vela 样式系统。
- 本机服务：Express + SQLite Profile 仓储。
- 桌面：Electron + electron-updater + contextBridge/IPC。
- 构建：`npm run build`
- 测试：`npm run test:node`
- Windows 包：`npm run build:win`

## 测试策略

- Profile 仓储测试覆盖新增字段、加密 Key、更新与脱敏。
- Electron 更新配置解析与状态归一化使用纯函数测试。
- TypeScript、Node 测试和生产构建必须通过。
- 在本机桌面版验证主页导航、主题持久化、API 表单、更新失败态和安装包启动。
- 视觉 QA 同时检查明亮首页、深色首页、API 页、设置页和黑色画布。

## 边界

- 始终：验证 URL/接口路径、隐藏密钥、保留用户现有项目和账户。
- 需用户后续提供：GitHub Release 及其 `latest.yml`、安装包、blockmap；真实私有仓库只读 Token。
- 不做：自动上传 Release、在前端保存明文 Token、直接执行 Git 拉取覆盖安装目录。

## 验收标准

- 左下角两个入口在 1050px 以上桌面尺寸始终可见。
- 重启软件后主题与画布颜色保持不变。
- 已保存 API 账户不显示真实 Key，可测试并读取模型。
- 桌面端更新按钮能进入“检查 / 可更新 / 下载 / 待安装 / 错误”状态；Web 端不误触安装。
- 原有项目、新建、打开、画布生成和算力入口无回归。
