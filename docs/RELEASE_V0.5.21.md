# V-MNH v0.5.21

v0.5.21 汇总了近期画布交互、生成服务、项目管理和 Windows 桌面体验改进。

## 主要更新

- 复制或创建节点副本时保留所选节点之间的内部连线。
- 新增稳定的 `Ctrl+Z` 撤销，并支持 `Ctrl+Shift+Z` / `Ctrl+Y` 重做。
- 全局字体与公共控件针对 2560×1440、Windows 125% / 150% 显示缩放优化。
- API 与画布算力配置统一管理，完善中转账户模型检测和安全错误信息。
- 支持 Boundless 视频中转、文生视频、图生视频以及云端 ComfyUI / H3 视频工作流。
- 支持从 Windows 桌面直接拖入图片，并完善尺寸、清晰度、张数与生成进度交互。
- 项目分享包、素材持久化、工作流模板和任务恢复能力得到增强。
- 节点阴影、连线可见性、中键画布拖动、任务中心与错误展示进一步完善。

## 安全与更新

- API Key、ComfyUI Token 和 GitHub Token 只在本机加密存储，不写入公开项目文件或 GitHub Release。
- Windows 安装包包含应用所需的 Electron 运行时和 Node.js 依赖，无需另外安装工程环境。
- 安装后可在设置页面检查 GitHub Releases 更新。

## 验证

- 生产构建通过。
- Node 自动测试 79/79 通过。
- 已验证节点复制保留连线、撤销与重做、2K 显示和 Windows 桌面启动流程。
