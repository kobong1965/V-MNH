# 视频编导与 Qwen 竞品脚本分析规格

## 目标

在 V-MNH 画布中增加两种可连接、可保存、可分享的文本能力：

1. **视频编导**：接收产品图与补充要求，按预设市场、人群和品类生成 10–15 秒带货脚本，并给出可直接交给视频模型的最终提示词。
2. **竞品视频分析**：接收一条对标视频和产品图，使用账号中单独配置的 Qwen 多模态模型分析镜头、节奏、钩子和卖点表达，再为当前产品生成原创脚本与视频提示词。

## 交互与节点

### 视频编导节点

- 输入：文本、产品图片。
- 输出：文本。
- 内置人设：
  - 越南接地气带货编导。
  - 美区小家电带货编导。
- 支持自定义：人设名称、目标市场、擅长品类、表达风格和输出语言。
- 节点输入区填写产品卖点、受众、禁用内容等补充要求。
- 点击生成后，把结构化脚本和最终视频提示词写回当前节点；节点可继续连接 Seedance、H3 等视频节点。

### 竞品视频分析节点

- 输入：文本、产品图片、视频。
- 输出：文本。
- 前端从视频中均匀抽取 8 帧，压缩后保存到当前项目素材目录。
- 后端将抽帧、产品图和补充要求发送给所选账号的 Qwen 分析模型。
- 输出包括：对标结构拆解、适合当前产品的原创 10–15 秒脚本、分镜、口播/字幕、最终视频提示词。
- 只学习表现方法，不复制竞品人物、品牌、水印、文案或受版权保护的具体画面。

## 模型与账号配置

- GPT/兼容账号新增独立字段 **Qwen 分析模型**，示例值由用户的中转站实际模型列表决定。
- 视频编导使用账号的“提示词模型”。
- 视频编导在每次生成前读取所选账户的模型列表，自动选择版本最高的 GPT 旗舰模型；优先识别 GPT 家族别名与 `-sol` 旗舰型号。
- 如果中转站没有返回可识别的 GPT 旗舰型号，则回退到账号已配置的“提示词模型”；实际命中的模型会显示在节点中并写入任务结果。
- 竞品视频分析必须使用“Qwen 分析模型”；未配置时禁止提交并给出明确提示。
- API Key 仍由本机后端加密保存，画布节点只保存账号 ID 和模型结果，不保存真实 Key。

## 数据与兼容性

- 项目、节点、人设参数、脚本、抽帧和产品图片都保存在本机项目目录。
- 任务队列只保存项目素材 URL，不把大体积 base64 写入任务 JSON。
- 旧账号缺少 Qwen 字段时按空字符串兼容，不影响原有图片、视频和提示词节点。
- 旧画布不迁移即可打开。

## 验收标准

- 新建菜单可添加“视频编导”和“竞品视频分析”。
- 产品图片可连接两种节点；视频可连接竞品分析节点。
- 视频编导可切换两种内置人设，并可填写自定义人设。
- 竞品分析节点能显示已连接的视频数、产品图数和当前 Qwen 模型。
- 竞品分析未连接视频、未连接产品图或未配置 Qwen 模型时不能提交。
- 成功任务将文本回写到节点并可继续连接下游视频节点。
- 保存并重开项目后，人设、补充要求和生成结果仍在。
- 视频编导能在账户同时提供多个 GPT 版本时自动命中最高旗舰版本，并在节点中显示上次实际使用的模型。
- Node 测试、TypeScript 检查和生产构建通过。

## 使用步骤

1. 在“API”页面添加或选择一个能列出 GPT 文本模型的 OpenAI 兼容账户，并确保 API Key 可用。
2. 在画布中添加“图片输入”和“视频编导”，把一张或多张清晰产品图连到视频编导左侧输入点。
3. 在节点底部选择 GPT 账户；“自动最高 GPT”状态会提示生成时自动检测，并显示配置模型作为故障回退。
4. 选择越南、美区小家电或自定义编导人设；在输入框补充卖点、目标人群、时长和禁用内容。
5. 点击右下角生成按钮。完成后节点会显示脚本和本次实际使用的 GPT 模型。
6. 可以直接修改脚本，或把视频编导右侧输出连接到 Seedance、H3 等视频节点继续生成。
