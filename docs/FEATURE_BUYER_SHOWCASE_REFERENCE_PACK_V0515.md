# 0.5.15 买家秀参考效果与分享包

## 目标

把“买家秀”项目简化为两段式工作流：先根据裤子商品图和一张拍摄效果参考图生成首张图，确认后再从首张图分裂出 5 个不同姿势。工作流可连同参考图打包分享给安装了 V-MNH 的同事。

## 已确认规则

- 只使用两个通用提示词：首图生成、姿势分裂。
- 提示词不写死裤子的颜色、版型、面料或细节；裤子信息只从商品参考图读取。
- 每套效果旁边保留原始拍摄效果参考图，首图生成同时读取裤子商品图与效果参考图。
- 首图必须复刻对应参考图的机位、距离、构图、裁切、背景关系、光线方向和阴影层次，不复制参考人物、服装、文字、水印或界面元素。
- 姿势分裂只读取已经确认的首图，后台提交 5 个独立请求，每个请求只生成 1 张完整照片，禁止五宫格、拼图和多面板；人物、裤子、上衣、鞋子、配饰、背景、机位、构图、光线和阴影保持一致，只改变自然姿势。
- 分享包包含画布节点、连线、分组、提示词和项目素材；不包含 API Key。接收者使用自己电脑中保存的生成账号。
- 当前实际收到 7 张参考图，先交付 7 套完整效果；第 8 套位置保留，收到图片后再补。

## 画布结构

```text
裤子商品图 ─┬─ 效果01首图（同时连接效果01参考图）─ 效果01姿势分裂×5
             ├─ 效果02首图（同时连接效果02参考图）─ 效果02姿势分裂×5
             ├─ ...
             └─ 效果07首图（同时连接效果07参考图）─ 效果07姿势分裂×5
```

每一套分组中从左到右放置“拍摄效果参考图 → 首图生成 → 5姿势分裂”，并显示清楚的效果编号和场景名称。

## 7 套参考效果

1. 普通住宅电梯口：竖幅全身，墙角和电梯形成纵深，普通住宅自然光。
2. 卧室落地镜近景：镜面视角，腰部到鞋的近景，轻微俯拍，木地板与床铺进入背景。
3. 凌乱宿舍全身照：正面全身，狭小宿舍和生活杂物，普通顶灯，随手拍质感。
4. 日系城市路口：正面全身，电线杆、路牌、建筑和道路纵深，阴天自然光。
5. 街边店铺墙面：正面全身，灰墙与店门交界，偏硬的自然日光与真实投影。
6. 雨天咖啡店门口：撑伞全身，店铺立面、湿路面、阴天漫射光和路面反光。
7. 街边镜面自拍：镜面边缘可见，正面全身，街道、车辆、树木和盲道作为真实背景。

## 分享与导入

- 首页项目菜单新增“分享打包”，下载扩展名为 `.vela` 的项目包。
- 首页新增“导入分享包”，选择同事发来的 `.vela` 文件后在本机创建独立副本并打开。
- 导入时所有项目内素材链接必须改写为新项目 ID，不能继续指向发送者项目。
- 导出前执行明文密钥检查；API Key、运行时密钥和本机账号凭据不进入分享包。

## 验收标准

- 7 张参考图都在对应分组旁可见，且分享后导入仍可打开。
- 两类生成节点分别只使用一个统一提示词。
- 首图节点输出 1 张；姿势分裂节点提交 5 个独立任务，每个任务输出 1 张，并注入不同的自然动作方向。
- 导入后的素材 URL 使用导入项目的新 ID，素材请求返回成功。
- 同事无需复制用户的 Key，只需在自己电脑选择已配置账号即可生成。
- Node 测试、TypeScript/Vite 构建、Windows 打包和原桌面快捷方式覆盖更新全部通过。
