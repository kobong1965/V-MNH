# v0.5.24 图片覆盖与画布文字标注

## Objective

让团队成员不用删除节点或重接连线，就能替换任意图片节点里的原图；同时允许给单个图片节点和一组工作流添加可读说明，便于把画布交给同事后快速理解每个节点和分支的用途。

## Assumptions

1. “覆盖原图”指更新当前节点的图片引用，不新建节点、不删除节点、不改变连线；旧素材文件不主动删除。
2. 单节点说明显示在图片上方，分组说明显示在包围框上方。
3. 说明文字和分组标题都随项目、自动保存、工作流模板和项目分享包持久化。
4. 第一版只提供文字、字号和颜色；不增加字体文件、富文本或自由旋转。

## Tech Stack and Structure

- React 19 + TypeScript：`src/components/canvas/` 画布交互。
- `NodeData` / `NodeGroup`：保存文字、字号、颜色。
- `useCanvasFileUpload`：复用项目媒体上传，替换后仍使用本地项目媒体 URL。
- `libtv.css` / `theme-dark.css`：沿用现有黑白主题和紧凑工具条。

## Commands

- 类型检查：`npx tsc --noEmit`
- Node 回归：`npm run test:node`
- 生产构建：`npm run build`
- Windows 打包：`npm run build:win`

## Interaction

### 图片覆盖

- 每个 `Image` 节点右上角显示“替换图片”按钮。
- 选择 JPG、PNG、WebP 等现有支持格式后，直接更新当前节点。
- 上传期间显示现有进度/加载状态；失败保留错误提示和重试能力。
- 替换成功后重新计算图片比例，清空旧的多图集合，节点 ID、位置、分组和连线保持不变。

### 节点文字标注

- 图片节点右上角提供“编辑文字标注”。
- 编辑器可输入多行说明，字号范围 12–72px，颜色使用颜色选择器。
- 空文字不显示标注；可一键清除。
- 标注显示在图片上方，画布缩放时跟随节点，但编辑面板保持可操作大小。

### 工作流分组命名

- 已打组节点的包围框显示分组名称。
- 选中整组后可打开“命名”编辑器，修改名称、字号和颜色。
- 双击分组名称也能打开编辑器。

## Testing Strategy

- TypeScript 校验数据字段和组件回调。
- 现有 Node 测试防止项目、媒体和分享包回归。
- 浏览器实测：替换图片不改变节点/连线；节点标注和分组名称可编辑、可保存、重开仍存在；浅色和深色画布可读。
- 桌面原位更新后验证原快捷方式、项目数、素材目录和账户配置连续。

## Boundaries

- Always：保留项目、节点 ID、连线、分组和本机素材数据；交互按钮使用原生 button/input 和中文 aria-label。
- Ask first：删除旧素材文件、引入第三方富文本库、改变分享包格式版本。
- Never：把 API Key 写入节点/工作流；替换图片时重建整个项目；未经本轮明确授权上传 GitHub。

## Success Criteria

1. 所有图片节点都能从右上角选择新图片并原位覆盖。
2. 覆盖后节点位置、父子连线和分组关系不变，新图在重开项目后仍可见。
3. 单图片节点可显示自定义文字，并自由修改 12–72px 字号与颜色。
4. 已打组工作流可显示和编辑组名、字号与颜色。
5. 浅色/深色画布均可操作；按钮支持键盘并有可读标签。

## Open Questions
