# 批量图片工作流实施计划

1. 在本机服务增加持久化批次仓库，复用项目、素材和任务模块，在一个项目内创建多个独立工作流分组。
2. 暴露批次创建、读取、选择启动和 Storyworks 同步清单接口。
3. 在首页增加“批量工厂”导航与三段式工作台：上传、共享配置、批次状态。
4. 增加防重复提交和数据契约测试，运行 Node 测试、TypeScript 和 Vite 构建。
5. 增加首页“批量工厂”项目分类与批量页“新建项目”入口，移除旧说明标题。
6. 将批量任务终态结果幂等回写项目节点，并在打开项目时自动修复历史遗留的 0% 节点。
7. 为新批次增加一张共享对标图输入；每个独立分组呈现商品原图与对标图双输入，并一起连接主图节点。
8. 为新批次增加可选姿势裂变后缀；复用现有 `pose-variation` 独立图片批处理，在主图完成后从当前结果生成多姿势图片。
9. 补齐输入验证、兼容性、画布阻断和响应式界面回归，升级补丁版本并原位更新现有安装。

主要风险是共享大图重复保存、双参考图顺序错误、后缀在主图完成前误提交和重复付费提交。通过单次保存对标素材、固定父节点顺序、姿势模式前置校验、创建与启动分离、保存 jobGroupId 后再禁用重复提交来控制。

## 多软件同步选择窗口

1. 扩展现有配对信息类型，向本机界面公开不含凭据的软件 ID、名称和连接时间。
2. 将批次同步从固定 Storyworks 目标扩展为多个已校验目标，并为每个目标保存独立清单。
3. 新增同步目标选择窗口，支持多选、刷新、记忆上次选择和逐目标结果。
4. 保持 Storyworks 旧清单读取方式兼容，补齐路由、仓库与配对回归测试。
5. 更新变更记录，验证不改写已有项目、批次、素材和连接令牌。

## AI 智能分析提示词

1. 复用 GPT 兼容账户的提示词/Qwen 分析模型，增加只接受少量产品图与对标图的视觉提示词分析接口。
2. 增加本机提示词模板仓库和列表、保存、删除接口，保持 API Key 与模板数据隔离。
3. 将提示词工作台拆成独立组件，提供模型选择、需求输入、分析预览、确认采用和已保存提示词选择。
4. 补齐供应商请求、路由持久化和安全回归；完成 TypeScript、生产构建、界面与安装连续性检查。

视觉分析属于可能计费的模型请求，因此不自动触发、不自动重试；提示词替换必须经过用户确认。为控制上传体积和模型理解混淆，一次只取前 4 张产品图并明确标注对标图角色。
