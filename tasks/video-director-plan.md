# 视频编导与 Qwen 竞品分析实施计划

1. 扩展节点目录、节点数据和账号模型字段，保持旧数据兼容。
2. 实现 OpenAI 兼容协议下的视频编导生成与 Qwen 多图分析请求。
3. 在运行时校验模型、读取本地素材并执行两类文本任务。
4. 增加视频均匀抽帧、画布连线校验和任务回写。
5. 完成节点控制面板与 API 设置界面。
6. 补充自动测试，执行 TypeScript、构建和桌面连续性验证。

## 风险控制

- 中转站的 Qwen 模型名称不统一：只提供独立可编辑字段，不硬编码某一家模型名。
- 对标视频过大：只抽取 8 张压缩帧，不上传整条视频。
- 模型输出照搬竞品：系统提示强制只提取结构与方法，生成原创表达。
- 本地任务膨胀：抽帧先存项目媒体目录，任务只引用 URL。
- 旧项目和旧账号：新增字段全部可选并提供默认值。
